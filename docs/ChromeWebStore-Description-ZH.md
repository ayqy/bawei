# bawei — 微信公众号文章多平台分发与公开验收

bawei 面向需要复用微信公众号文章的内容作者。打开 `mp.weixin.qq.com` 文章页后，选择保存草稿或正式发布，bawei 会提取标题、结构化正文、受支持的图片和可选原文链接，再逐个串行处理所选渠道。

## 支持渠道

- CSDN
- 腾讯云开发者社区
- 博客园（CNBlogs）
- OSCHINA
- 人人都是产品经理（WoShiPM）
- 墨问
- 少数派（SSPAI）
- 百家号
- 头条号
- 飞书文档

## 核心能力

- 严格串行处理渠道，同一时间只操作一个编辑器。
- 在目标编辑器支持的范围内保留标题、段落、列表、链接和图片结构。
- 对支持的渠道把图片上传为平台托管资源，不把本机临时地址或图片代理地址当成公开结果。
- 同时支持保存草稿与正式投稿。
- 明确区分七类结果：匿名公开成功、待审核、已退回、待人工安全验证、技术失败、未登录和重复跳过。
- 使用“渠道 + 内容哈希”防止重复投稿；待审核只复核公开状态，已退回和待人工验证会保留现场，不会静默重投。
- 正式发布只有在无 Cookie 的全新匿名上下文中打开公开详情页，并通过标题、正文锚点和预期平台托管图片验收后，才计为成功。

## 隐私与权限

bawei 在 Chrome 本地运行，不运营文章处理中转服务器。文章内容只从你选中的页面读取，并发送到你主动选择的发布平台。扩展使用 storage 保存本地设置与发布状态，使用 tabs 打开和聚焦目标编辑器，使用 scripting 自动填写页面，并仅为受支持的图片传输与本地 Markdown 发布申请必要的受限站点访问权限。

## 使用边界

登录、验证码、实名认证、必填项、审核和最终公开时间均由各平台控制，bawei 不绕过这些保护。仅点击投稿按钮，或文章只在登录后的后台列表可见，都不会被报告为公开成功。若平台编辑器改版或操作被拦截，bawei 会保留浏览器现场并返回具体阻塞原因，方便安全检查和后续修复。
